# Data sources

The repository does **not** contain third-party data. Download each source from the official provider under its licence, then build the files below (procedure in `data_preparation/`; see the limits stated in the README) and place them in `data/raw/`. `data/MANIFIESTO_COPIA.csv` lists the size and hash of the files used in the published run.
